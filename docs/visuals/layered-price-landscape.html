Reference and interpretation

Reference: 50% cocoa, 100 g pack, 15 g sugar/100 g; organic, nuts and single origin all false. The six traits explain the hand-authored model's price output relative to that one fictional reference.

All contributions in these fixtures are nonnegative relative to this low-price reference. Real signed contributions need a different display; they must not be clipped or converted to absolute values.

Map positions use centered PCA of six price-contribution profiles, not observed or proposed prices. Projection loses information; proximity is approximate. Colored dots sample each product's own stack. Nothing is interpolated between products.

There are exactly 500 fictional product records. Increasing samples per layer draws more dots within each stack; it does not add products or change the benchmark.
