# Lifecycle specification

Follow the [feature specifications](../spec.md) and
[documentation policy](../documentation-policy.md). Update implementation guides
when behavior changes and record verification in the [plan](plan.md).

Preserve original evidence, persistent seller identity, fixed contracts during
processing, and immutable downstream snapshots. Distinguish implemented code,
reviewed evidence, evaluated extraction and validated models.

Private research documents own actual populations, source coverage, study
assumptions, case decisions and outcomes. Public documents must not depend on
those ignored files being available in a clean checkout.
