# Model intention

Estimate selected relationships only when the evidence, study design and actual
inputs support them. Keep prediction, association and causal claims distinct.
Validate support, uncertainty and reproducibility before release.

Dataset-owned designs define targets, comparison groups, feature rules and
validation requirements. Private documents hold selected populations, hypotheses,
source decisions and results. Git retains training interfaces and general methods.
See [model interfaces](spec.md) and [artifact maintenance](../model-maintenance.md).
