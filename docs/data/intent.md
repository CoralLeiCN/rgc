# Data intention

Preserve original product evidence and prepare useful analytical facts without
losing source identity, uncertainty or the meaning of a declaration. Support
category configuration and separate seller listings throughout the workflow.

Bronze owns original records and artifacts. Silver owns standardized facts,
persistent source identity, corrections and profiling. Gold owns the selected
comparison population, target, features and model-input preparation.

Keep study intentions, researched categories, retailer inventories, raw examples,
coverage measurements and case decisions in ignored local documentation.
Analytical schemas, mappings, validators, recipes and model designs belong in
the authoritative dataset. Git retains small immutable references and the
implementation that verifies and consumes them.

See [data interfaces](spec.md), [contract ownership](dataset-contracts.md), and
[documentation storage rules](../documentation-policy.md).
