# Project intention

Build a reproducible workflow for product evidence, analytical data, models and
an evidence explorer. Preserve provenance, distinguish supported facts from
claims, and make uncertainty visible.

The [data intention](data/intent.md), [model intention](model/intent.md) and
[app intention](app/intent.md) own their respective goals. The
[specification overview](spec.md) describes shared interfaces.

Research subjects, source lists, category decisions and experimental results are
private working material. Keep them in ignored local documents and dataset
artifacts. Git retains implementation guidance, generic methods and validation
of software behavior. Schema definitions belong to the dataset, with only
immutable resolution references retained in Git.
