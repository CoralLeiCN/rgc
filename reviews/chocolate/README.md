# Reviewed identity mappings

The identity registry is an implementation input, distinct from the analytical
schema. `scripts/chocolate_standardization/identity.py` validates its format and
applies exact source selectors and original-name guards. Keep seller rows separate;
family identity does not establish an exact physical variant.

An explicit registry can be supplied through `--family-mappings` on the historical
builder. Snapshot outputs preserve its exact bytes and hash. New or changed
captures need renewed evidence assessment before prior decisions can apply.

The private documentation archive preserves earlier research narratives and
assignment summaries. Public implementation guidance must not reproduce seller
inventories, named family catalogs, original product examples or review counts.
